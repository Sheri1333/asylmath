# MATH ASYL

ҰБТ математикасына дайындық: лендинг, жеке кабинет, сабақ және тақырыптық тест. Стек: **React + Vite** және **Node + Express + MongoDB**. Прод: `http://195.49.212.31:8080` (сол VPS, порт 8080, API `:3002`).

## Запуск

```bash
# 1. Зависимости
npm install
npm install --prefix server

# 2. MongoDB должна быть доступна (по умолчанию localhost:27017)
#    Настройки: server/.env

# 3. Сид: админ + демо-курсы
npm run seed

# 4. API (порт 3001)
npm run server

# 5. Фронт (порт 5173)
npm run dev
```

Откройте http://localhost:5173

## Возможности

- Каталог курсов с фильтром по предмету
- Карточка курса и программа уроков
- Запись на курс, прогресс, отметка урока пройденным
- Регистрация / вход (JWT)
- Админка: CRUD курсов и уроков, статистика, пользователи

## API (кратко)

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/auth/login` | Вход |
| POST | `/api/auth/register` | Регистрация |
| GET | `/api/courses` | Каталог |
| GET | `/api/courses/:idOrSlug` | Курс + уроки |
| POST | `/api/enrollments/:courseId` | Запись |
| GET | `/api/admin/*` | Админ |
